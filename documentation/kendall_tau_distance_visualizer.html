Kendall Tau Distance (Visual Demo)

Kendall Tau distance counts how many pairwise inversions exist between two orderings. An inversion happens when two items swap their relative order.

How this matches your Python function:
  • We only compare common items between the two sequences.
  • We count inversions: for each pair (a,b), if their order differs → +1.
  • Maximum inversions for n items = n(n-1)/2.
